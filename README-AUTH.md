# HomeHealth AI — Real Authentication Starter

This starter adds a Node.js/Express authentication backend for the existing HomeHealth AI login page.

## Railway variables required

- DATABASE_URL: reference Railway PostgreSQL's DATABASE_URL
- SESSION_SECRET: create a long random secret in Railway Variables

Never commit real passwords, database credentials, API keys, or PHI to GitHub.

## Important

This is a development/MVP authentication foundation. Before using real patient information or production healthcare workloads, add appropriate security, access control, audit logging, monitoring, backup/recovery, MFA/SSO, and HIPAA/security compliance controls.
